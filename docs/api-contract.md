# Фронтенд и API рекомендаций

Контракт утверждает техлид (KIR-02): `api-contract.md` и `architecture.md` в репозитории бэкенда. Здесь — как фронтенд этот контракт использует (EGO-01…05) и что нужно от бэкенда, чтобы всё сошлось.

## Контракт коротко

- `GET /health` → `200 {"status": "ok"}`
- `POST /api/v1/recommendations`, тело `{"symptom": "<жалоба свободным текстом, 3–500 знаков>"}`
- `200 {"status": "match", "recommendations": [{rule_id, parameter, direction, change_description, expected_effect, limitations, basis}]}`
- `200 {"status": "no_match", "message": "…"}`
- `400 {"status": "error", "error": {"code": "validation_error", "message": "…", "fields": {"symptom": "…"}}}`
- `500 {"status": "error", "error": {"code": "internal_error", "message": "…"}}`

Типы на фронте — `src/assistant/types.ts`, клиент — `src/assistant/api.ts`.

## Как форма собирает жалобу (EGO-01)

Поле запроса одно — `symptom`. Форма помогает его сформулировать:

| Что в форме | Что попадает в `symptom` |
|---|---|
| Подсказка «что делает машина» (необязательно) | каноническая фраза по-русски: «недостаточная поворачиваемость», «пробуксовка задних колёс на выходе из поворота»… |
| «Где в повороте» — только для недо- и избыточной поворачиваемости | «на входе в поворот», «в середине поворота», «на выходе из поворота» |
| «В каких поворотах» | «в медленных поворотах», «в быстрых поворотах» или ничего |
| «Своими словами» | текст пилота как есть |

Части склеиваются через точку: `Недостаточная поворачиваемость в середине поворота. В Пуоне передок уходит наружу`. Пилот видит ровно этот текст в блоке «Уйдёт ассистенту» со счётчиком до 500 знаков. Перед отправкой фронт проверяет те же границы 3–500, что и бэкенд.

Фразы подсказок — в `PHRASES_RU` (`src/assistant/types.ts`). Их стоит сверить со словарём VAR-02 и условиями правил VAR-04: бэкенд ищет совпадение по словам, и подсказки должны содержать те же слова, что условия правил.

## Как фронт показывает ответ (EGO-02, EGO-03)

| Ответ | Экран |
|---|---|
| `match` | «Нашли правку», карточки: параметр, «Увеличить» / «Уменьшить», `change_description`, «Что изменится», «За чем следить», правило и основание |
| `no_match` | «Подходящего правила нет» и `message` бэкенда |
| `400` (и стандартный `422` FastAPI) | «Сервер не принял запрос», `error.message`, поля из `error.fields` |
| `5xx` | «Ошибка на сервере (код)», `error.message`, «Повторить» |
| нет ответа за 15 с, нет сети | «Сервер не отвечает», «Повторить» |
| `200`, но не по контракту, или `match` с пустым списком | «Непонятный ответ сервера» |

## Подключение (EGO-04)

- Без адреса API ассистент работает на демо-правилах `src/assistant/demoRules.ts` и пишет об этом.
- Адрес: при сборке `VITE_API_URL=http://localhost:8000 npm run build`, или в браузере `…/ru/app/?api=http://localhost:8000` — запоминается, `?api=demo` возвращает заглушку.
- Пока FastAPI нет, можно поднять фейковый бэкенд строго по контракту: `node scripts/fake-backend.mjs` (порт 8765, жалоба с `#500` даёт внутреннюю ошибку).

## Проверка целиком (EGO-05)

```bash
npm run build && npx vite preview --port 4173
node scripts/e2e.mjs                                                         # заглушка
node scripts/e2e.mjs http://localhost:4173/simracing-setups/ http://localhost:8000   # живой бэкенд
```

## Что нужно от бэкенда (Родион)

1. **CORS.** Фронт живёт на `https://kom1sh.github.io` и локально на `:5173` и `:4173`:
   ```python
   from fastapi.middleware.cors import CORSMiddleware
   app.add_middleware(CORSMiddleware, allow_origins=["http://localhost:5173", "http://localhost:4173", "https://kom1sh.github.io"], allow_methods=["GET", "POST"], allow_headers=["Content-Type"])
   ```
2. **400 вместо 422.** FastAPI по умолчанию отвечает на невалидное тело кодом 422 в своём формате. Чтобы был `400` из контракта, нужен обработчик `RequestValidationError`. Фронт понимает оба варианта, но тест ROD-05 должен проверять контрактный.
3. **`match` — только с непустым списком.** Если правил нет, — `no_match`.

## Открытые вопросы к контракту (Кирилл)

1. **Язык.** Правила и словарь — русские, сопоставление по словам. Лендинг и кабинет есть на английском: подсказки уходят по-русски, а английский текст пилота правило может не найти. Варианты: английские синонимы в словаре VAR-02 или необязательное поле `locale` в следующей версии контракта.
2. **`limitations` — одна строка.** Если ограничений несколько, удобнее массив; пока фронт показывает строку как есть.
3. **Аутентификация вне MVP** — согласовано: вход и регистрация на фронте локальные (кука в браузере) и бэкенда не касаются.
