# Бэкенд: аккаунты, сетапы и ИИ-ассистент

Код — `backend/` (Python 3.14, FastAPI, SQLAlchemy, SQLite, Alembic). Работает на hq за nginx: https://simracing.egorprotasov.ru. Всё бесплатно: модель — Groq (бесплатный тариф), база — SQLite.

Версия Родиона (ALE-03) — в архиве `archive/backend-rodion-ale03/` (ветка `archive/team-mvp-2026-10-20`, тег `mvp-ale03-2026-10-20`). Её контракт `/api/v1/recommendations` сохранён.

## API

| Метод | Что делает |
|---|---|
| `GET /health`, `GET /api/v2/status` | жив ли сервер; есть ли ИИ и сколько кусков руководств в базе знаний |
| `POST /api/v2/auth/register` · `login` · `logout`, `GET /api/v2/auth/me` | аккаунты: пароль — argon2id, сессия — httpOnly-кука `srs_sid` (в базе только sha256 токена), подсказка `srs_in` для статических страниц; 20 попыток за 10 минут с адреса |
| `GET/POST /api/v2/setups`, `GET/POST /api/v2/setups/{id}`, `POST /api/v2/setups/{id}/delete` | сетапы пользователя на сервере |
| `GET /api/v2/catalog` | классы, машины, трассы и гаражи iRacing (тот же каталог, что в кабинете) |
| `GET /api/v2/knowledge/effects` | таблица эффектов с цитатами — для проверки командой |
| `POST /api/v2/advice` | совет ассистента |
| `POST /api/v2/advice/{id}/feedback` | отзыв «лучше / так же / хуже» и время круга до/после |
| `GET /api/v2/advice` | история советов |
| `POST /api/v1/recommendations` | ALE-03: экспертные правила из таблицы `rules` |

Ошибки — как в ALE-03: `{"status": "error", "error": {"code", "message", "fields"}}`. Документация OpenAPI — `/api/docs` (наружу nginx её не пускает).

## Как ассистент выбирает правку

1. **Диагноз.** Кнопки в форме (симптом, фаза, когда) — или модель разбирает текст пилота (gpt-oss-120b, запасная — gpt-oss-20b). Нет модели — разбор по словам (`app/advice/keywords.py`, русский сленг и английский).
2. **Кандидаты** — только строки таблицы эффектов `app/data/effects/*.json`: регулировка, направление, какой симптом и в какой фазе лечит, цитата из руководства iRacing. 45 строк, все 48 фрагментов цитат сверены с текстом руководств. Фильтр: класс машины, есть ли регулировка (ABS/TC), правки с отзывом «хуже» не предлагаются.
3. **Модель выбирает** 1–3 кандидата по строгой JSON-схеме: id — только из списка кандидатов, поэтому посоветовать регулировку «не туда» или несуществующую она не может. Видит машину, трассу, погоду, уже сделанные правки, историю и куски руководств (база знаний, FTS5).
4. **Проверка** по гаражу машины (шаблон класса с отличиями из её руководства, `carGarages` в `src/data/carSetup.ts`): шаг в пределах диапазона, у выбора из списка — соседний вариант. У обратных шкал (`inverted`: «клики от закрытого», ABS и TC у Mercedes-AMG) знак правки меняется, у выбора «как в базе» — крайний вариант.
5. **Без модели** (лимит, сеть) совет собирается по той же таблице — режим «по таблице правок, без ИИ».

Лимиты Groq (бесплатно): 1000 запросов в день, 8000 токенов в минуту. Совет — около 3000 токенов, поэтому на пользователя — 40 советов в день (`SIMRACING_ADVICE_DAILY_LIMIT`).

## База знаний

`python -m app.knowledge.build` скачивает 19 руководств iRacing (`app/data/manuals.json`), режет на разделы-регулировки (`pdftotext -layout` + разрезка колонок) и кладёт в `knowledge_chunks` + FTS5. Текст руководств в репозиторий не кладём. На hq — 830 кусков.

## Тесты и проверка качества

- `pytest` в `backend/` — 57 тестов: аккаунты, сетапы, ALE-03, целостность таблицы эффектов (каждый класс покрывает недостаточную и избыточную на входе, в середине и на выходе), ассистент с подменной моделью (выбор только из кандидатов, режим без ИИ, вопрос, отзыв «хуже», лимит, шаги в пределах).
- Золотой набор `backend/eval/golden.json` — 16 жалоб пилотов на всех классах с допустимыми правками. Прогон против настоящей модели: `scripts/deploy-hq.sh golden` (отчёт — `backend/eval/last-report.json` на сервере).
- Фронт: `node scripts/e2e.mjs`, `smoke.mjs`, `qa.mjs` против сборки `SITE_BASE=/` и бэкенда на :8000.

## Локально

```bash
cd backend && python -m venv .venv && .venv/bin/pip install -r requirements-dev.txt
SIMRACING_DATA_DIR=./data SIMRACING_COOKIE_SECURE=0 .venv/bin/alembic upgrade head
SIMRACING_DATA_DIR=./data SIMRACING_COOKIE_SECURE=0 GROQ_API_KEY=... .venv/bin/uvicorn app.main:app --port 8000
# фронт: SITE_BASE=/ npm run build && SITE_BASE=/ npx vite preview --port 4173 (прокси /api на :8000)
```
