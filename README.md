# Сетапы для симрейсинга

Командный университетский проект: ассистент по настройке машины в iRacing. Пилот описывает, что делает машина, и получает одну–три правки сетапа в щелчках с ожидаемым эффектом и ограничениями. Ответы — только из проверенных экспертных правил.

Сайт: https://kom1sh.github.io/simracing-setups/

## Страницы

| Адрес | Что там |
|---|---|
| `/` | выбор языка по браузеру |
| `/en/`, `/ru/` | лендинг, статический HTML для поиска |
| `/en/signup/`, `/en/login/` | регистрация и вход |
| `/en/app/` | кабинет, только после входа |

## Что умеет

- **Лендинг.** Понятный заголовок и пример «жалоба пилота → ответ ассистента», что такое сетап, как это работает, схемы недо- и избыточной поворачиваемости, симптомы, принципы, цифры исследования, вопросы. Фото — по ТЗ [docs/images-brief.md](docs/images-brief.md), без них страница тоже собирается. Meta, canonical, hreflang, Open Graph, JSON-LD (WebSite, WebApplication, FAQPage), sitemap.
- **Аккаунт.** Регистрация, вход, «не выходить на этом устройстве», выход. Пока без сервера: аккаунты и сессия в куках браузера, пароль — только PBKDF2-хэш с солью (`src/lib/session.ts`). Сетапы у каждого аккаунта свои.
- **Кабинет.** Трасса со схемой, погода и покрытие, категория и машина, все регулировки шаблона GT3, расчёт топлива, проверка противоречий, сохранение и файлы. На двух языках.
- **Ассистент.** Жалоба пилота (подсказки + свои слова) → `POST /api/v1/recommendations` по контракту техлида → карточки рекомендаций. Состояния: ожидание, поиск, найдено, правила нет, сервер не принял запрос, ошибка сервера, нет сети. Как форма собирает жалобу и что нужно от бэкенда — [docs/api-contract.md](docs/api-contract.md).

Пока бэкенд не подключён, ассистент отвечает демо-правилами из фронтенда и пишет об этом. Подключить живой API: `…/ru/app/?api=http://localhost:8000` или `VITE_API_URL` при сборке. Фейковый бэкенд строго по контракту: `node scripts/fake-backend.mjs` (порт 8765).

## Запуск

```bash
npm install
npm run dev        # http://localhost:5173/simracing-setups/
npm run build      # типы, сборка, пререндер лендинга в dist/
```

Проверки (нужен Google Chrome):

```bash
npm run build && npx vite preview --port 4173
node scripts/e2e.mjs        # сквозная: вход, кабинет, ассистент во всех состояниях, SEO-разметка
node scripts/e2e.mjs http://localhost:4173/simracing-setups/ http://localhost:8765   # то же с бэкендом
npm run smoke               # поведение кабинета
npm run qa                  # вёрстка кабинета на четырёх ширинах
node scripts/site-shots.mjs # снимки лендинга, входа и ассистента в .qa/site
node scripts/media.mjs      # пересобрать снимки кабинета и OG-картинки в public/
```

Публикация на GitHub Pages идёт сама после пуша в `main` или `frontend` (`.github/workflows/pages.yml`).

## Устройство

```
app.html, auth.html, site.html   входы сборки: кабинет, вход, скрипт лендинга
src/
  site/        лендинг: тексты en/ru, разметка, пререндер (render.tsx), клиентский скрипт
  auth/        вход и регистрация
  assistant/   форма жалобы, ответ, карточка рекомендации, клиент API, демо-правила
  i18n/        язык из адреса, словари кабинета, входа и ассистента, английские подписи данных
  data/        трассы, машины, шаблон регулировок, условия; localized.ts — на языке страницы
  lib/         сессия, форматирование, топливо, проверки
  fonts/       Roboto Flex с осями opsz, wght, wdth (scripts/build-font.py)
scripts/prerender.mjs   после сборки раскладывает страницы по /en/ и /ru/, пишет sitemap и 404
```

Дизайн описан в `DESIGN.md`.

## Откуда данные

- **Схемы трасс:** [bacinger/f1-circuits](https://github.com/bacinger/f1-circuits) (MIT) и [OpenStreetMap](https://www.openstreetmap.org/copyright) (ODbL, © участники OpenStreetMap).
- **Длина и число поворотов:** открытые источники, ссылки в `factSources` у каждой трассы.
- **Машины:** Википедия и сайты производителей, ссылки в `sources`. Где источник не подтвердил значение, стоит `null`, и кабинет эту строку не показывает.
- **Характер трассы, диапазоны и база регулировок:** оценка и общий шаблон класса, а не данные конкретного симулятора. Так и подписано в интерфейсе.
- **Цифры на лендинге:** опрос 41 пилота и 4 глубинных интервью (сентябрь 2026), цены магазинов сетапов на 21.09.2026.
- **Шрифт:** Roboto Flex (OFL) из `@fontsource-variable/roboto-flex`.
