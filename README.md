# Сетапы для симрейсинга

Командный университетский проект. Кабинет, где гонщик выбирает трассу, задаёт условия заезда, выбирает категорию и машину и собирает сетап.

Сайт: https://kom1sh.github.io/simracing-setups/

## Что умеет

- **Трасса.** Выпадающий список со схемами трасс и названием на картинке, поиск по русскому и оригинальному названию и по стране. Стрелки ходят по плиткам, Enter выбирает.
- **Машина.** Категории GT3, GT4, GT2 и кубковые, поиск по марке и модели во всех категориях.
- **Трасса и погода.** Характер трассы (прижим, неровности, бордюры), сессия, погода, покрытие.
- **Машина.** Шины, электроника, топливо и тормоза, механика, амортизаторы, аэродинамика — шаблон класса GT3. Регулировки по колёсам стоят вокруг схемы машины, левую и правую сторону можно менять вместе.
- **Сводка.** Что изменено против базы, расчёт топлива на гонку, проверка противоречий (слики под дождём, не хватит топлива, отрицательный наклон кузова).
- **Хранение.** Сетапы сохраняются в браузере, их можно скачать файлом и загрузить обратно.

## Запуск

```bash
npm install
npm run dev        # http://localhost:5173/simracing-setups/
npm run build      # проверка типов и сборка в dist/
```

Проверка вёрстки на четырёх ширинах экрана (нужен установленный Google Chrome):

```bash
npm run build && npx vite preview --port 4173
npm run qa              # геометрия: прокрутка вбок, обрезанный текст, вылет за блок
npm run smoke           # поведение: выбор трассы и машины, симметрия, сохранение, файл
node scripts/shots.mjs  # крупные снимки блоков в .qa/shots
```

Публикация на GitHub Pages идёт сама после пуша в `main` (workflow `.github/workflows/pages.yml`).

## Устройство

```
src/
  data/
    tracks.json      схемы и факты трасс
    cars.json        машины по категориям
    trackMeta.ts     характер трасс для сетапа и синонимы для поиска
    carSetup.ts      шаблон регулировок GT3: группы, диапазоны, база, подсказки
    conditions.ts    условия заезда
  lib/               форматирование чисел, расчёт топлива, проверки
  components/        выбор трассы и машины, строки регулировок, сводка
  styles/            токены и стили; значения токенов описаны в DESIGN.md
```

Дизайн описан в `DESIGN.md`: белый каталог регулировок, чёрная полоса со схемой трассы, жёлтый — только у выбранного.

## Откуда данные

- **Схемы трасс:** [bacinger/f1-circuits](https://github.com/bacinger/f1-circuits) (MIT) и [OpenStreetMap](https://www.openstreetmap.org/copyright) (ODbL, © участники OpenStreetMap).
- **Длина и число поворотов:** открытые источники, ссылки лежат в `factSources` у каждой трассы.
- **Машины:** Википедия и сайты производителей, ссылки лежат в `sources`. Где источник не подтвердил значение, стоит `null`, и кабинет эту строку не показывает.
- **Характер трассы, диапазоны и база регулировок:** это оценка и общий шаблон класса, а не данные конкретного симулятора. Так и подписано в интерфейсе.
